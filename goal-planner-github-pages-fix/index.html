使用說明與公式

怎麼使用？
  1. 點上方的目標標籤切換，或按「＋新增目標」，選旅行、緊急預備金、購屋頭期款等範本。
  2. 在左側填入目標金額、目前存款、年數與預期報酬率。
  3. 右側會立即顯示「每月應存金額」。你也可以拖曳滑桿，看看自己的存法能累積多少。
  4. 圖表和總覽表會同步更新，幫你比較不同目標的負擔。
三個關鍵名詞

PV（現值）：你現在手上已經有的錢。FV（終值）：未來某一天這筆錢加上持續投入後會變成多少。PMT：每個月固定存進去的金額。

計算公式（月複利、每月月底投入）

月利率 r = 年報酬率 ÷ 12，期數 n = 年數 × 12

未來資產：FV = PV×(1+r)ⁿ + PMT×[((1+r)ⁿ−1)÷r]

每月應存：PMT = (目標 − PV×(1+r)ⁿ) × r ÷ ((1+r)ⁿ−1)

想一次存到目標，今天要有：PV = 目標 ÷ (1+r)ⁿ。若報酬率為 0%，則 PMT = (目標 − PV) ÷ n。

注意事項

本工具為教育試算，未計入稅費、通膨與市場波動。緊急預備金建議放在低風險、可隨時提領的帳戶。你的資料只儲存在這個瀏覽器中。

本頁僅供試算參考，不構成任何投資建議。
